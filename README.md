# dawidolko.pl - Portfolio

Personal portfolio website built with React.js.

## Features

- Modern, responsive design with dark theme and emerald/teal accent colors
- Project showcase with GitHub, Demo, and YouTube links
- Personal blog section with stories and experiences
- Resume/CV viewer with PDF download
- Professional skillset and toolstack display
- GitHub activity calendar
- Links to WorkStation app and social media profiles

## Tech Stack

- **React.js** - UI framework
- **React Bootstrap** - Component library
- **React Router** - Client-side routing
- **TypeWriter Effect** - Animated typing
- **React Parallax Tilt** - 3D tilt effects
- **TSParticles** - Particle background animation
- **React GitHub Calendar** - GitHub activity display
- **React PDF** - CV/Resume viewer

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## Deployment

The site is automatically deployed to GitHub Pages via GitHub Actions workflow on push to the `main` branch.

**Live:** [https://dawidolko.pl](https://dawidolko.pl)
